# Entendendo Métodos em Java - DIO Orange Tech+

Repositório criado durante o bootcamp Orange Tech+ Backend da DIO,
documentando meu aprendizado sobre métodos em Java.

## Conteúdo

### Criação de Métodos
- Conceituação → o que são métodos e para que servem
- Definição → estrutura completa de um método
- Conceitos inerentes e boas práticas na criação
- Exercício prático

### Sobrecarga de Métodos
- Como criar sobrecargas e quando utilizá-las
- Mesmo nome de método com parâmetros diferentes
- Exercício prático

### Retornos
- Funcionamento e considerações sobre retornos
- Tipos de retorno → void, int, double, String, boolean
- Exercício prático

## Tecnologias

- Java 17
- IntelliJ IDEA
- Git e GitHub
